# Carbon Output Notes

CARBINE should expose carbon pools only when they are available and defensible from inspected FVS outputs. Current UI labels are placeholders for the eventual parser contract:

- Live tree carbon
- Standing dead carbon where supported
- Down dead wood carbon where supported
- Biomass carbon where supported
- Harvested/removal carbon where supported
- Selected pool total carbon

Soil carbon is excluded from the MVP until FVS documentation and outputs provide a clear basis for including it.
